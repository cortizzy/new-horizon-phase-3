# New Horizons Phase 3

A multi-page commercial and industrial construction website built as a static, shared-hosting-compatible project.

## Structure

- `index.html` — main homepage
- `css/` — shared stylesheets
- `js/` — shared JavaScript
- `pages/` — experience, services, industries, projects, and contact
- `services/` — individual specialty service pages
- `industries/` — industry-specific pages

## Preview

Use a local static server:

```sh
python -m http.server 8000
```

Visit `http://localhost:8000`.

## Before publishing

Verify all contact details, scope descriptions, capabilities, service availability, and approved photography. Replace stock imagery with authorized project photos before public launch. The contact form prepares an email through the visitor's email application and does not send server-side submissions.
